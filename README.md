# ETK_Inofficial_Website - Experience using Claude Design

*This project used Claude's Opus 5.5 model with effort set to 'high'.*

*All the input data/assets is inside the 'assets' and 'uploads'.*


What I was impressed by:

- Claude managed to turn simple, short and abstract instruction into professional looking website
- Whenever you order Claude to add or change something, Claude would even consider minor details (although that may be more due to Effort being set to ‘high’)
- Claude proved to be able to implement complex things that worked well (e.g. the Model Viewer in the model configurator)

What not:

- Responsive design was neither implemented as standard nor completely and correctly implemented upon request
- I was a bit disappoint that you could only download the project as simple HTML, CSS and JS (not accounting for non-code options). I would have expected more.
- As expected from an LLM, Claude wrote a lot of non-sensical placeholder text. It also placed the images in locations that they don’t make sense in and needed to be instructed to use all the provided images (to be fair I never specified what images should be used where and never provided any specific text to display so this is also partially my fault)

Conclusion:

I am impressed by Claude Design, I could have never made this website in under 4 days than it took with Design, even when utilizing LLMs the ‘tradition’ way. I don’t think I will work further on this fun, little project even though there would be a lot of fine-tuning and improving (especially the car models) left to do.

If you’d like to, feel free to clone this repository and fun with it!
